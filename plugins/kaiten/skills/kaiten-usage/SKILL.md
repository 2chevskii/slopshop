# Kaiten with MCP

Before working with Kaiten, check whether Kaiten MCP tools are available. If missing or unable to connect, explain that Kaiten MCP must be installed and configured with the company origin and API token. Refer to the [Kaiten MCP setup](https://github.com/2chevskii/kaiten-mcp#get-started). Never request a token in chat or put one in a repository file.

Discover the relevant space, board, and cards using the available tool schemas. Resolve ambiguous matches before modifying a card. Read enough context to satisfy the request, and report links or identifiers where available. Make changes only within the user's request. Changes take effect immediately; after a timed-out write, inspect the affected item before retrying to avoid duplicates.
